Days → story points

Configure the SP value for each number of available days. This mapping applies to all teams and sprints and is included in backups.
Use nonnegative whole SP values. Available days remain whole numbers from 0 to 10; 0 days always equals 0 SP. Changes immediately recalculate member and net capacity. Defaults: 1 → 1, 2 → 2, 3 → 3, 4–6 → 5, 7–8 → 7, 9–10 → 10 SP.
Works offline with no sign-in. Changes save in this browser, not in the downloaded file. Return using the same file and browser. Clearing browser data or private browsing can remove plans; export backups to keep them safe.
